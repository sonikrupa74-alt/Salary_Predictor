# Salary Prediction System 💼

## Overview

This project is a machine learning-based salary prediction system that estimates employee salaries based on experience and input features. It provides real-time predictions through a frontend interface integrated with a FastAPI backend.

## Tech Stack

* Python
* pandas, NumPy, scikit-learn
* FastAPI
* HTML, CSS, JavaScript
* Render (Deployment)

## Features

* Real-time salary prediction
* Data preprocessing and regression model training
* Frontend and backend integration
* REST API-based prediction system
* Deployed and accessible online

## How It Works

1. User enters input details in the frontend
2. Frontend sends request to FastAPI backend
3. Machine learning model predicts salary
4. Result is displayed instantly

## Result

* Built an end-to-end salary prediction system
* Demonstrates complete ML workflow (data → preprocessing → model → API → frontend)
* Integrated frontend with backend for real-time interaction
